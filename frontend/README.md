# LeadPilot AI

LeadPilot AI is an AI-powered Lead Analytics Dashboard built using Next.js 16, React 19, TypeScript and Tailwind CSS.

## Features

- CSV Upload
- KPI Dashboard
- Revenue Analytics
- Lead Growth Analytics
- Conversion Analytics
- Status Distribution
- Search
- Filter
- Sorting
- Pagination
- Export CSV
- AI Insights
- Responsive Dashboard

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Recharts
- PapaParse
- Lucide React

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Start Production

```bash
npm start
```
